01

核心公式：三句话，句句有他

先证明看过帖子，再谈房源

1

复述硬条件

第一句必须出现帖子里的 1–2 个具体信息：预算、学校/校区、起租时间、房型、通勤分钟、地标。

→
2

给对得上的信息

只讲一个和他条件直接相关的方案或事实。不铺产品清单，不先夸自己房源多。

→
3

给低门槛下一步

只给一个动作：发实拍、发路线、发对比表、拉群。第一次绝不直接要微信。

判断标准：把这条私信发给另一个学生，如果完全不违和，说明你写的还是套话。

通用套话

“同学你好，看到你在找 UCL 附近的房子，我们这边有很多优质房源，可以加微信详聊～”

  • 没有复述任何条件
  • 信息量为零，像群发
  • 第一步就要微信，门槛太高
需求点前置

“预算 300pw 以内、想步行到 UCL 的 studio，我这边有两套对得上：一套 King's Cross 步行 18 分钟、独卫；一套 Euston 通勤 12 分钟但临街。你更在意走路近还是安静？我先发这两套的实拍。”

  • 数字和条件全部来自他的帖子
  • 给了取舍，不是堆房源
  • 下一步只是“发实拍”
02

5 种开头公式

按帖子里最醒目的信息选一种

01 数字复述

预算 + 通勤时间

把两个数字拎出来，证明你会算账。

“300pw 以内 + 步行 20 分钟到校区，这个组合我这边有两套能对上。”
02 地标复述

校区 / 公寓 / 商超

用他提到的地名，而不是泛泛说“学校附近”。

“你说的 Jubilee Campus 附近，我按门到门算了下，这套步行 12 分钟。”
03 时间复述

起租日 + 租期

短租和转租最在意时间，先把日期对上。

“9 月 15 号起租、只住到 12 月，这个租期我有两类方案能接。”
04 取舍复述

两个条件互相打架

点出他的矛盾，显得你真的在替他筛。

“又要独卫又想压预算，筛选范围会小很多，我按优先级帮你排一下。”
05 对比复述

在 A 和 B 之间纠结

接住他的纠结，而不是重新推一套。

“你已经在 A 和 B 之间选了，说明预算和位置都锁定了，主要差在通勤和安静。”
禁用开头

这些话不要出现在第一句

“同学你好，看到你在找房” · “我们这边房源很多” · “方便加个微信吗” · “私信你了”

共同问题：没有他的任何信息，学生一秒判定是群发。
03

需求点识别速查表

看到这些信号，第一句就这么接

帖子信号他真正在意的第一句怎么接（需求点前置）
标题带「急转 / 短租」+ 起止日期时间和确定性“X 月 X 号起、租到 X 月，时间上正好能对上，我这边有两类方案……”
写明预算 / 「学生党」绝不超预算“预算 X 以内还要……，这个范围我按价格从低到高给你筛。”
「步行到 XX 学校」通勤与安全“步行 X 分钟内到 XX，我按门到门算过，这套是 X 分钟。”
「studio / ensuite / 独卫」隐私与生活习惯“不想共用卫浴，那基本就是 studio 或带独卫的 ensuite……”
「可养宠 / 双人入住」特殊准入条件“带宠物 / 两个人住，能选的公寓会少一些，我先按这个条件筛……”
「找室友 / 拼 2b」室友匹配度“你写的是 XX 学校、X 月入住、想找女生室友，我这边正好有同校同时段的……”
「XX 公寓怎么样 / 求避雷」决策信息“你在纠结 XX 公寓，主要顾虑是隔音还是到校区距离？”
「新生 / 求组织」归属感与信息“27fall XX 学校的组织，里面同专业的同学挺多……”
04

分场景话术

私信版 + 留评版 + 提醒

A

预算型帖子

信号：明确写“X pw 以内”“预算有限”

他最先划掉的就是超预算的房源，所以第一句先把预算复述出来，再给“在预算内但需要取舍”的方案。

私信版

“预算 250pw 以内、还要能步行到 XX 学校，这个组合确实不多。我手上能对上的是一套合租单间，£2XX/周含 bill，步行 15 分钟到校区，缺点是厨房共用。你能接受合租吗？能的话我把房间实拍和室友情况发你。”

留评版

“250pw 以内 + 步行到 XX 的房源不多，我这有一套合租单间刚好在预算内，私你实拍看看？”

提醒：不要为了成交先推超预算的房源。先说“这个预算需要接受什么”，信任感反而更高。

B

通勤 / 位置型帖子

信号：“步行到学校”“离地铁近”“不想坐公交”

通勤型学生最怕中介嘴上说“很近”。用分钟数和路线证明，而不是形容词。

私信版

“你说的步行 20 分钟内到 UCL，我按门到门算了下：A 公寓步行 18 分钟，B 公寓地铁 12 分钟但要换乘。你更想全程走路，还是接受地铁？我把两条路线截图发你，你自己感受下距离。”

留评版

“步行 18 分钟到 UCL 这个距离我这边正好有对应房源，私你路线图～”

提醒：把“步行 / 地铁 / 公交”的分钟数分开写，别用“交通便利”四个字糊过去。

C

短租 / 转租型帖子

信号：“急转”“只租 X 个月”“X 月起租”

这类学生最怕“聊半天结果租期接不上”。第一句就把日期对上，比任何介绍都有效。

私信版

“9 月 15 号起租、只住到 12 月，这个租期大部分公寓不接，我这边有两类方案：官方短租和学长转租。你更在意价格，还是能开发票 / 走正规合同？我先按你的优先级筛，不合适的直接排除。”

留评版

“9–12 月这个租期我有转租资源，私你细节？”

提醒：转租一定先确认能否走官方合同、押金怎么处理，别为了快而模糊带过。

D

房型 / 设施型帖子

信号：“studio”“独卫”“能做饭”“双人入住”“可养宠”

硬性设施是筛选项，不是卖点。先确认他的硬条件，再谈价格，顺序不能反。

私信版

“不想共用卫浴 + 要能自己做饭，那基本就是 studio 或带厨房的 ensuite。你预算大概多少？我按『独卫 + 可做饭 + 到 XX 学校通勤』三个条件一起筛，避免给你推超预算的。”

留评版

“独卫 + 能做饭，我这边有 studio 对得上，私你看户型？”

提醒：“可养宠”“双人入住”属于稀缺条件，先确认公寓政策再承诺，避免后面翻车。

E

拼室友 / 找室友型帖子

信号：“找女生室友”“同校拼 2b”“作息规律”

拼室友的核心不是房源，是“人能不能合得来”。先复述他的室友条件，再谈房子。

私信版

“你写的是 XX 学校、X 月入住、想找女生室友，我这边正好有同校同时间段的同学在拼 2b。你们作息要求对得上吗？对得上我拉个小群先认识一下，房子可以后面一起看。”

留评版

“同校 X 月入住拼室友，我这边有匹配的同学，私你？”

提醒：先拉小群认识、再谈房，成交率和口碑都比硬推房源好。

F

新生 / 求组织型帖子

信号：“27fall”“求组织”“找搭子”“求学姐”

新生要的是归属感，不是房源。先给组织价值，再自然过渡到租房。

私信版

“27fall XX 学校的组织要来吗？里面同专业的同学挺多，可以找搭子、问选课和租房。要进的话我拉你，进群先看看氛围，不合适也没关系。”

留评版

“27fall XX 学校组织，要进可 dd～”

提醒：可用群列表 / 群聊截图增强真实感，但务必打码同学昵称和头像。

G

求推荐 / 求避雷型帖子

信号：“XX 公寓怎么样”“求避雷”“哪个好”

他已经在做决策，不需要你再推一套新房，而是帮他把纠结点说清楚。

私信版

“你在纠结 XX 公寓，主要顾虑是隔音还是到校区距离？这两个点我这边都有实际反馈：隔音一般但位置好，另一套正好反过来。你更在意哪个？我按你的取舍发对比，不硬推。”

留评版

“XX 公寓的优缺点我整理了一版，私你？”

提醒：讲缺点要具体（隔音、临街、距离），但别贬低同行、别编造负面。

H

已看房 / 两套纠结型帖子

信号：“A 和 B 选哪个”“已经看了几套”

不要重新推第三套。先复述他纠结的两个选项，再给一个判断维度。

私信版

“你已经在 A 和 B 之间选了，说明预算和位置都锁定了。A 的优势是 XX，B 是 XX；如果你更在意 Z，我会选 B。你现在最纠结的是哪一点？我帮你把这一点确认掉。”

留评版

“A 和 B 我这边都有实际入住反馈，私你对比一下？”

提醒：给建议而不是替他决定，最后一句一定要把选择权还给他。

I

公开留评截流

用在别人的求租帖 / 求助帖下

评论区只做两件事：对上他的条件 + 留一个钩子。不写价格细节，不留微信。

留评示例

“预算 / 位置和我手上这套对得上，私你实拍和价格～”

“同校同租期，我这有匹配的房源 / 室友，dd 我发你。”

“你说的 步行 15 分钟到校区，我这边有套正好在这个距离，私你路线？”

提醒：不要复制同一句评论刷多个帖子；被平台判定营销会限流。评论里不出现“加V”“微信”“看我主页”。

J

私信截流（针对帖子）

用在已确认有真实需求的学生

不要用“看到你发的帖子”当开头——那不是需求点。直接把帖子里的条件写进第一句。

私信版

“X 月入住、预算 X、要独卫，这三个条件我这边有一套正好对上，£X/周，到 XX 学校步行 12 分钟。先发你实拍和户型，不合适也没关系。”

提醒：先按「时效性 + 真实需求 + 租期预算位置」筛一遍再发；素人号 10 条/天、KOS 20 条/天，别浪费在同行帖上。

05

回访与群内跟进

加上微信之后，话术才真正开始

K

加微信后的首次破冰

刚通过好友
跟进话术

“刚加你微信，先不给你发房源轰炸。你之前说的三个条件我记下了：预算 X、X 月入住、步行到 XX。我这周按这三个条件筛，有对得上的先发你 2 套，不合适直接说。”

提醒：先复述条件 = 证明你记住了他。比“有什么可以帮你”有效十倍。

L

3–7 天后二次跟进

客户未回复 / 还在观望
跟进话术

“上次说的 XX 公寓这周放了几间 X 月的房，价格在 £X–X，和你预算对得上。要我把楼层和朝向发你吗？或者你已经有别的选择了，也跟我说一声，我就不重复打扰。”

提醒：每次跟进都要带一个新信息（新房源、价格变化、截止时间），不要只发“在吗”。

M

沉默客户唤醒

长期不回消息
跟进话术

“你之前关注的是 XX 学校附近、X 月入住，现在时间更近了。我这边新出两套在预算内的，其中一套步行 X 分钟。还需要的话我发你；如果已经定好了也告诉我一声，恭喜你～”

提醒：给台阶、不施压。明确说“不需要我就不打扰”，反而更容易收到回复。

N

拉群后同步顾问 / 群内立人设

建群第一分钟
群内话术

“@同学 这位是 XX 顾问，专门负责 XX 区域。你的需求我已经同步了：XX 学校、X 月入住、预算 X、要独卫。顾问老师会按这个给你筛，不会推超预算的。”

“大家有问题直接在群里问，租房、选课、找室友都可以，看到都会回～”

提醒：先替顾问立住“专业靠谱”人设，再让顾问开口，破冰会顺很多。

O

每周一大回访

按城市 / 学校标签群发
回访话术

“周一大回访～你之前看的是 XX 区域，这周新上了 X 套，其中一套价格比之前低 £X。还想看的话我发你；如果已经定好了也跟我说一声，我就不打扰啦。”

回访内容库

热门房源推荐 / 拼室友匹配 / 活动策划 / 询问最新租房需求。

提醒：按城市、学校维度打标签再群发，避免把伦敦的房源发给利兹的学生。

06

通用填空模板

任何帖子都能套，但必须填满括号

模板 1 · 条件对得上

“X 月入住、预算 X 以内、要独卫——这三个条件我这边有一套正好对上，£X/周。先发你实拍和户型，不合适也没关系。”

模板 2 · 需要取舍

“你说的『步行到 XX 学校』我按门到门算过，这套是 X 分钟。你更在意近，还是安静？我按你的选择再筛，不给你堆一堆用不上的。”

模板 3 · 时间紧

“X 月 X 号起租、只住到 X 月，时间上我这边能接。你更在意价格，还是合同正规？我先按这个优先级帮你排，今天就能给你两套对比。”

模板 4 · 拼室友

“你写的是 XX 学校、X 月入住、想找 女生室友，我这边有同校同时段的同学。你们作息对得上吗？对得上我先拉个小群，房子后面一起看。”

注意：括号里的内容必须来自帖子或对话，不能凭感觉填。填不满，就说明你还没看懂他的需求，先别发。

07

发布前 4 秒自检

一条不过，就重写

CHECK 1有没有出现他帖子里的 1 个具体条件？（数字 / 地名 / 日期）
CHECK 2有没有一句只属于他、换个人就不成立的话？
CHECK 3下一步是不是只有一个动作，且门槛足够低？
CHECK 4有没有超预算、超范围硬推，或第一句就要微信？
  • 先筛后发：时效性 → 真实需求 → 租期 / 预算 / 位置，四项都过再私信。
  • 甄别同行：IP 跳动（疑似梯子）、主页内容异常、IP 集中在河南 / 河北 / 天津 / 广东的，谨慎私信。
  • 私信上限：素人号 10 条 / 天，KOS 20 条 / 天，把额度留给真实客户。
  • 不硬承诺：价格、房态、能否养宠 / 双人入住，一律以系统与公寓政策为准。
  • 公开评论区：不留微信、手机号，不刷重复评论。
  • 时间节点：所有获客动作在 18:00 质检前完成。
